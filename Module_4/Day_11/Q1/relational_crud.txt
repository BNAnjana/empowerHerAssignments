foreign key (user_id) references users(id));

Conceptual Question (Short Answer)

-- Why should orders not be stored inside the users table?

-- Orders should not be stored inside the users table because
-- one user can have multiple orders (1-to-many relationship).
-- If we store them together it breaks normalization, makes queries
-- difficult, and does not scale as the number of orders grows.
